# AldenLee28.github.io

Personal portfolio site — [aldenlee28.github.io](https://aldenlee28.github.io).
Built with [Astro](https://astro.build) and deployed to GitHub Pages.

Sections: **Portfolio** (projects grouped into Tech and Finance, with a Featured
row), **Valuations** (DCF reports generated by my valuation engine), **Resume**,
and a **Blog**.

## Running locally

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # production build to ./dist/
```

## Editing the site

Content is Markdown/JSON under `src/content/`; adding a project or blog post is a
one-file change. See **[GUIDE.md](GUIDE.md)** for how to add pages, edit the
homepage, change the theme, and publish.

Pushing to `main` triggers the GitHub Actions workflow, which builds and deploys
automatically.
